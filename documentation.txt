8. DEVELOPMENT METHOD
==================================================

Step 1:
The assignment requirements were studied and the required
portfolio sections were identified.

Step 2:
A project folder named "rashi-portfolio" was created.

Step 3:
The main HTML file, index.html, was created.

Step 4:
The CSS file, style.css, was created and connected to
index.html.

Step 5:
The JavaScript file, script.js, was created and connected
to index.html.

Step 6:
The basic portfolio structure was created using HTML.

Step 7:
CSS was used to create the visual design, layout,
buttons, project cards, navigation and other components.

Step 8:
Responsive CSS media queries were added so that the
website works on desktop, tablet and mobile screens.

Step 9:
JavaScript was added for the mobile navigation menu and
contact form interaction.

Step 10:
A personal profile image was added to the website as
"profile.jpg".

Step 11:
Personal information was added, including name, college,
course, roll number, batch, email, GitHub and LinkedIn.

Step 12:
The website was tested locally using Live Server in
Visual Studio Code.

Step 13:
A public GitHub repository named "rashi-portfolio" was
created.

Step 14:
The website files were uploaded to the GitHub repository.

Step 15:
GitHub Pages was enabled using the main branch and the
root directory.

Step 16:
The website was deployed and tested using the public
GitHub Pages URL.

Step 17:
This documentation file was created and added to the
portfolio so that it can be downloaded using the
"Download Documentation" button.
